VR
TOOL_01

Velociraptor

DFIR / Endpoint Hunting

An open-source digital forensics and incident response platform for collecting endpoint evidence, investigating suspicious activity, and hunting threats across many machines.

WHAT YOU LEARN

How professional responders ask focused questions across endpoints and collect the evidence needed to answer them.

VOLUME 02 NOTE

Version 0.77 introduced interactive shell sessions that append commands to one flow, alongside memory-analysis and detection capabilities.

V3
TOOL_02

Volatility 3

Forensics / Memory Analysis

An open-source, cross-platform framework that examines RAM captures to rebuild execution state without depending on the target operating system.

WHAT YOU LEARN

How analysts find malware persistence, processes, injected code, and other short-lived evidence stored in memory.

BEST FOR

Live threat hunting, post-breach investigation, and learning why volatile evidence can reveal what a disk image misses.

FW
TOOL_03

Fern Wifi Cracker

Wireless / Linux GUI

A graphical Linux tool that automates WEP and WPA key-recovery workflows. Its approachable interface makes common wireless-auditing steps easier to learn and execute in a controlled lab.

＋ ADVANTAGE

Beginner-friendly interface with useful automation for early wireless security labs.

− LIMITATION

Slower and less flexible than command-line alternatives; struggles against modern encryption.

A#
TOOL_04

Aircrack-ng

Wireless / CLI Suite

An industry-standard command-line suite for packet capture, WEP and WPA-PSK key auditing, wireless traffic injection, and end-to-end assessment of Wi-Fi networks.

＋ ADVANTAGE

Powerful, scriptable, well established, and flexible enough for advanced workflows.

− LIMITATION

Steep learning curve and requires a wireless adapter capable of monitor mode.

SK
TOOL_05

Starkiller

Post-Exploitation / GUI

A graphical front end for the Empire post-exploitation framework, simplifying the management of agents, modules, listeners, and tasks after authorized access is established.

＋ ADVANTAGE

Reduces operational friction and makes complex Empire workflows easier to manage visually.

− LIMITATION

Requires Empire in the background and its activity is readily flagged by modern AV and EDR.
