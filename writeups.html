01CVE-2025-32711
AI SecurityWritten by Abner RebelloResearch by Atiya Srivastava

EchoLeak: The First Real-World Zero-Click Prompt Injection Exploit in a Production LLM System

Malicious instructions embedded in ordinary content—such as an email—could trick Microsoft 365 Copilot into exposing sensitive data without the user clicking, approving, or interacting.

Open research note

EchoLeak collapses the boundary between “data the model reads” and “instructions the model follows.” An attacker plants adversarial text in content the assistant later retrieves. When the model processes it inside a privileged enterprise context, that text can steer output toward sensitive information.

The zero-click property matters because the victim only needs to use the AI assistant normally. Effective defense requires strict separation of instructions from retrieved data, output controls, least-privilege connectors, and security testing that treats every external document as untrusted.

02V-TRIAD
Applied AIWritten by Srinidi SubramaniamResearch by Shivank Kakkad

Devising and Detecting Phishing Emails Using Large Language Models

An exploration of how models such as GPT-4 can generate convincing phishing emails and also detect them with high accuracy, evaluated through the V-Triad methodology.

Open research note

The same language fluency that helps users write can help attackers remove spelling errors, adapt tone, and personalize pretexts at scale. Yet models can also analyze linguistic cues, urgency, identity mismatches, and suspicious calls to action.

The V-Triad approach frames evaluation across the message’s validity, veracity, and vector. The research argues for human-in-the-loop detection: use model judgment as one signal alongside authentication results, URL analysis, sender reputation, and behavioral telemetry.

03ZERO TRUST
Cloud SecurityWritten by Srinidi SubramaniamResearch by Shivank Kakkad

Cybersecurity in Agile Cloud Computing: Guidelines for Secure Cloud Access

A cloud access framework built on Zero Trust, multi-factor authentication, role-based access control, encryption, and continuous monitoring.

Open research note

Agility expands the number of identities, services, environments, and automated changes that defenders must govern. Static perimeter assumptions cannot keep up with short-lived workloads and distributed data.

The proposed framework continuously verifies identity and context, limits privileges by role, encrypts data in transit and at rest, and watches for drift. Security becomes a repeated decision embedded in the cloud lifecycle rather than a one-time gate.

04CVSS 10.0
Vulnerability SpotlightBy Rahul BeheraActively Exploited

SonicWall SMA 1000 Zero-Days Under Active Attack

CVE-2026-15409 and CVE-2026-15410 affected SonicWall SMA 1000 VPN gateways, with exploitation observed for roughly three weeks before patches and later weaponization by the INC ransomware group.

Open vulnerability brief

CVE-2026-15409 carried a critical CVSS score of 10.0, while the paired vulnerability broadened the attack path. Internet-facing remote-access appliances are especially sensitive because compromise can create an entry point behind perimeter controls.

Both vulnerabilities were added to CISA’s Known Exploited Vulnerabilities catalog. Defenders should patch immediately, investigate appliance logs and configuration changes, rotate potentially exposed credentials, and validate that the management surface is not unnecessarily internet-accessible.

05NEXT-GEN
Future DefenseBy Deetya ShivathayaPQC + Agentic SOC

Post-Quantum Cryptography & Agentic Defense

How quantum-resistant cryptography and autonomous AI-driven SOC agents are moving network defense toward systems that can anticipate, adapt, and heal.

Open research note

Post-quantum cryptography prepares today’s data and protocols for adversaries with tomorrow’s computing power. Migration requires crypto-agility: knowing where algorithms live, which data must stay confidential, and how systems will rotate to new standards.

Agentic SOC systems add a second frontier by gathering context, proposing containment, and coordinating response. Autonomy should be bounded by auditable policies, approval gates for destructive actions, and resilient fallbacks. The goal is not unattended power—it is faster defense with explicit control.
